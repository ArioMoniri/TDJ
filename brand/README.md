# TDJ brand
Three concepts were built, audited and tested with the logo-design skill (`brand/concepts/concepts.png`). **A · Tanda arc** is in use: the night as a record groove, opened where the tanda line rises (slow → up → settle). B (four bars + cortina crossbar) and C (abrazo) remain available if you prefer; switch by replacing `brand/logo.svg` and `apps/web/src/components/Logo.tsx`.

Files: `logo.svg` (colour), `logo-mono.svg`, `lockup.svg` (symbol + constructed TDJ letterforms, no live text), `logo-animated.svg` (README), `variants/` (black, white, square, favicon, app icon), `logo-512.png`, `lockup.png`.
Colour: rose `#e0557a` (primary actions only), gold `#e8b85a` (golden age), teal `#4fd1c5` (vals), violet `#8b7cf6` (milonga), ink `#0b0a10`, cream `#f6f1e8`. Type: serif display (New York / Playfair) for headlines, SF Pro / Inter for UI.
