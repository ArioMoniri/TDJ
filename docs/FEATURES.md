# T-DJ in detail

The README keeps to the short version. This page is the long one: every feature, how a set is built, every way to
deploy, the stack and the index of the other docs.

## Everything it does
- **Composes a milonga** for 1–8 h: TTVTTM cycles, 4-3-3 tandas, one orchestra · one singer · ≤ 4 years per tanda, no repeats, orchestras spaced.
- **Shapes the night**: warm-up → build → peak → cool-down → **La Cumparsita**, or a *double peak* with a real breather between (Arc shape, nights ≥ 3 h); marathons get a second rise and a lower vocal share. Inside each tanda: slow → up → strongest → settle (or *hammock*, *rising*, *flat*).
- **Matches cortinas** to the energy of the *next* tanda; choose cultures (Turkish, Greek, Persian, Balkan, Brazilian, K-pop, Afrobeats…), trend vs classic, length, or one cortina all night; at least 8 distinct per 4 h, never the same one twice in a row, an era-matched family as a stated fallback (the Turkish family alone holds 36).
- **Any era**: Golden Age 1935–55 (default), Guardia Vieja, post-golden, nuevo, contemporary, or everything.
- **Index lives in the repo** (`data/`): 19,119 recordings merged from 21,932 spreadsheet rows (duplicates folded, transcriptions flagged and kept out of tandas), orchestra × year quality heatmap, musicology profiles, Spotify cache — rebuilt with `pnpm index:build`, enriched with `pnpm index:enrich`.
- **Knows the canon**: a reference corpus of 31 published milonga sets (619 tandas), 218 canonical tandas, 1,078 floor-known recordings and 134 non-danceable titles drives openers, D'Arienzo-early, Pugliese-once-and-late, vals/milonga banks and the Cumparsita versions DJs actually close with ([docs/AGENT_GUIDE.md](AGENT_GUIDE.md)).
- **Reads the room**: season, weather, room temperature, time of night, event type, crowd, region, holiday and mood shift the arc, shares and cortina pools, each factor graded by evidence ([docs/research/context-factors.md](research/context-factors.md)).
- **Takes feedback**: "more energetic", "calmer start", "more vals", "fewer repeats" chips, or free text to the AI DJ (Anthropic, OpenAI, Gemini or OpenRouter, your own key), recomposing around the tandas you locked.
- **Your own database**: every deployed copy has a Database tab where songs, years, orchestra profiles, cortinas, rules and context factors can be edited and exported; overrides merge over the repo-hosted index that GitHub keeps updated.
- **Listen before you commit**: a play button on every song (30 s previews resolved from Deezer for 1,134 reference recordings, full tracks when Spotify is connected) with a mini-player, plus reference tanda playlists for a mood check.
- **Hears the records**: a pure-TypeScript analyser (FFT, chroma, Krumhansl key, octave-folded tempo, loudness, brightness) measured key, BPM and loudness for 690 recordings and runs in your browser for any song with a preview; every tanda shows a cohesion badge (tempo · loudness · key · brightness · energy) built on the model in [docs/research/audio-features.md](research/audio-features.md).
- **Finds and fixes metadata**: "Find on services…" looks a song up on Deezer and MusicBrainz, shows candidates with previews, and offers one-tap year/singer corrections into your database (recording dates only from MusicBrainz, never from reissues).
- **Booth**: play the night from the app ([docs/specs/round7-booth.md](specs/round7-booth.md), [docs/research/booth.md](research/booth.md)). Your own files (a folder linked once on Chromium, matched by title, orchestra and year) through Web Audio with sample-accurate gaps, BS.1770 loudness normalisation with a −1 dBFS peak cap, cortinas from their cue-in with a −60 dB log fade that reaches silence at the planned stop, a cortina fader, master, level meter, hold / next-at-gap / emergency stop, birthday vals and breaks; Spotify Premium through the Web Playback SDK as a second source (Spotify Connect to the Spotify app where the view has no Widevine: iPhone, iPad and the Mac app, which picks the Spotify app on that Mac); YouTube's official embedded player, on screen, with the videos the YouTube export matched (the night's source, or the fallback before clips); 30 s previews as a rehearsal mode. Set-up and Settings → Booth list what can play on this device, each with one line on how or why not. Dark, readable at 2 m (what plays, what is next, the clock, the time to La Cumparsita), keyboard-driven, with Wake Lock, OS media controls and a resumable position; the plan the booth plays is the plan every export writes its cue points from, and the night's log lands in History.
- **A featured night**: the engine's best 4 h golden-era (1935–45) set with 4-tango tandas, Turkish cortinas and a double peak ships with the app (seed 181 after four working-DJ review rounds and a comparison with 11 published DJ sets; engine 93, every side and cortina resolved on Spotify; listing in docs/specs/round11-best-night.md). Open it from the home hero, the Booth onboarding or `/?featured=golden-double-peak`, then play it in the Booth or send it to Spotify with the cortinas in running order (or paste a playlist link to update one made before).
- **Benchmark against published DJ sets**: every composed night shows how it compares with 11 published milonga sets (D'Arienzo count, orchestra variety, vals/milonga share, Pugliese placement, La Cumparsita, core canon, instrumental share per hour, cortina length and culture; docs/reviews/benchmark-reference-sets.md). "Improve automatically" iterates fixes (instrumentals of the same orchestra and years, stream-suspect sides, cue fit, side order) and keeps a change only if neither the engine score nor the benchmark falls; Keep or Undo (docs/specs/round12-benchmark.md).
- **Honest scores**: hard failures (an undated or transcription tanda, a milonga inside a tango tanda, a night more than 10 % off its length, a broken Pugliese cap) cap the score at 60 and print their reason under the number; "Tell the DJ" never shrinks a night by more than 10 % and reports what it applied and what it could not.
- **Swap is a choice, with undo**: a song's Swap shows the engine's (or your AI's) pick as a suggestion and the smart search; a tanda's Swap builds a replacement from suggested whole tandas or sides you search, add, remove and reorder (drag, the arrows, Alt+↑/↓), the tanda rules shown live, applied through the rule check (in the Booth, the tanda that plays next asks first). One undo history for swaps, moves, adds, removes and pins: ⌘Z / Ctrl+Z, ⇧⌘Z / Ctrl+Shift+Z / Ctrl+Y, the toast's Undo and the Mac app's Edit menu; S on a focused row opens its Swap.
- **Insert and remove anywhere, with a guide**: on Compose (each card, the inspector, before the first and after the última), the Booth's set list ahead of the playhead, Rooms and Build by hand — "Add song here" at a place, "Remove song", "Insert tanda before / after", "Remove tanda" (its cortina handled: one cortina per gap, never two alike in a row, the última's by the closing format). Each insert offers the engine's candidates ranked for that exact spot with a one-line why (a side of the tanda's family at its neighbours' energy and tempo; a tanda at the energy the arc wants there, keeping the rhythm cycle, the big-four spread and the repeat gaps; a succession score when the engine has one), the smart search and "Ask my AI". After the rule check, the guide says what the edit did — the night's length, an energy bump, two vals tandas side by side, a cortina added or removed, a big-four or orchestra repeat — with a one-tap fix, and when the first or last tanda changed it checks the opening and closing La Cumparsita ("Tanda 1 is now Di Sarli 1940: switch the opening La Cumparsita to Di Sarli 1951?") with apply / keep (core `insert.ts`).
- **The last La Cumparsita** (Settings → Night): after the última's cortina, straight after it (today's default), 4 + 1 (the fifth song of a four-song última, the same orchestra preferred), its own tanda of one, or none; the opening La Cumparsita on or off. The composer, the Booth's plan and time to La Cumparsita and every export follow it; a stored night (the featured one) keeps its own format.
- **Change the end in the Booth**: +10 / +20 / +30, −10 / −20 min or "End at HH:MM" adds or removes whole tandas after the playing one (never the última, never a locked tanda), keeping the rhythm cycle, the big four, the repeat gaps and "last 4 tandas tango only", the arc re-planned for the new length and La Cumparsita matched again; a preview shows the new end against the target, the tandas added and removed and the energy before and after; Apply (asks once mid-night), Undo (core `nightEnd.ts`).
- **Every Booth action undoes, every key is yours**: Skip next, Cortina early, birthday vals, a break, Hold, Rest then La Cumparsita, Skip tonight, Last 4 tandas tango only, start points, gain trims, the gaps and the silence settings, floor reactions and praise go into the same undo history ("Undid: Skip next (Ahora No Me Conocés)" with Redo); what the room already heard (Next now, Previous, a fade) says why it cannot be undone. Settings → Keyboard lists every shortcut and records new ones on this device (conflicts named, reset to defaults); the Booth's keyboard sheet shows them as set.
- **Exported playlists follow the night**: a Spotify or YouTube playlist made from a night is rewritten 5 s after each change of it (Compose, Build by hand, the Booth, a room, an undo), read back and repaired, never inside a Spotify Connect play burst, with its cover redrawn from the night (Spotify; YouTube shows its first video); the Export sheet and the Booth's night bar show the state with Retry. Files (M3U8, rekordbox…) are copies and do not follow.
- **Rooms edit the whole night**: the opening, every tanda as Compose's card with its songs and cortina, the closing, with the same swaps, reorders (drag, Alt+↑/↓), locks, Skip tonight, pre-listen, rule check and undo, synced to every DJ; start a room with any night (open now, History, featured), the owner switches it or closes the room for everyone; idle rooms expire after 30 days.
- **One smart search** in every search box (Swap, Library, Database, Build by hand, Find songs, the Booth): typo- and accent-tolerant completions of titles, orchestras and singers (Tab takes one), "Did you mean", chips for rhythm, voice, era, decade, orchestra and singer, and once a title is complete its versions by work — orchestra, singer or Instrumental, year, the Tango / Vals / Milonga badge, length, BPM and energy, where each comes from (the catalogue, your Spotify, a linked file), play on tap; your Spotify's recordings merged in (the same recording one row).
- **Import a playlist** (`/import`; from Compose's first run and its ••• menu, the Library, History, Settings and Rooms): a Spotify playlist (a pasted link, or your own playlists with your Spotify login, every page, in your country's market), a YouTube / YouTube Music playlist (your Google login), a DJ app's file or folder (M3U / M3U8, XSPF, Rekordbox XML, Traktor NML, Serato / Lexicon / DJ CSV, TuneMyMusic / Soundiiz / Exportify CSV, T-DJ's own CSV and `.tdjnight`, a folder of "Orchestra - Title" audio files) or a pasted "Title – Orchestra" list. Each row is matched to the catalogue with the export match rules (another orchestra, singer, take, a tribute orchestra or album are refused; accents and typos tolerated) and a confidence (sure / likely / guess); a row the catalogue lacks stays as its service's recording (`ext:spotify:<id>`, a YouTube video) so it still plays. The list is split into tandas and cortinas (the file's marks, non-tango, short or repeated rows, runs of one orchestra and rhythm; a first / last La Cumparsita opens / closes) for you to review: each tanda's type, what it breaks shown as information and allowed for that night only, split / merge / mark-as-cortina. Then Open in Compose, Play in the Booth or Start a room; it lands in History as an imported night with its source link (kept linked for sync). It teaches nothing unless you choose "Learn from this night". T-DJ's own exports re-import as the same night.
- **Song details and Song DNA**: one details sheet behind every song (Compose's menu, Library and search ⓘ, the Database, the Booth's song sheet): length, Instrumental or the singer, the rhythm badge, the recording date and album, BPM / key / energy, the work's credits (Música · Letra · year written, `data/knowledge/works.json`), where the singer comes in and the first downbeat falls (the DJ's "Mark now" while it plays, or measured from the DJ's own file: music start, first beat and downbeat by onset detection), lyrics from LRCLIB (lrclib.net, open and keyless; time-synced lines follow the playing second; credited; kept per side on the device, never bundled) and every other version of the work from the catalogue and the DJ's Spotify, playable and, in the Booth, usable tonight. Song DNA pages (`/song?id=`, `/orchestra?id=`, `/singer?id=`; an overlay inside the Booth) show every recording of the work on a timeline, the orchestra's and the singer's year around it, the tanda family it fits and the classic tandas that hold it, related works by the same authors, and the DJ's own nights, floor reactions and hearts with it. The Booth's "Now playing" view puts the artwork, synced lyrics, a rhythm lane (beats, bars, 8-bar phrases, the singer's entry) and the matched YouTube video (muted, following the Booth's clock; never the room's sound) on one screen. Database → Orchestras: every singer and the instrumentals open their sides, playable one by one or all.
- **History**: every composed, refined or swapped set is kept (50 in the browser, the newest on the server when enabled) with a score trend, compare sheet, rename, reopen and re-export.
- **Editable guide**: the DJ guide and your house rules are yours to edit; house rules travel with every AI review and refine.
- **Scores every set** honestly against what a professional-DJ audit measures: first D'Arienzo early and instrumental, Pugliese once and late, a strong última, a Cumparsita from a year DJs actually close with, role-ordered tandas, energy steps, cortina fit, context compliance, obscurity share and analysed cohesion; unscored factors drop out of the denominator. ≥ 85 = headline marathon DJ (the default 4 h set scores 87–91 across 12 seeds).
- **Exports**: Spotify (PKCE, your own Client ID), M3U8, CSV, JSON, Rekordbox XML, Traktor NML, XSPF, DJ CSV, printable set list; with or without cortinas; DJ-app connectors map exports to your music folders. In the Mac and iPhone / iPad apps every file goes to the native save panel (Files on iOS); every "Open in Spotify / YouTube / YouTube Music / Apple Music" link opens the service's app when it is installed (universal links on iOS, the app's own scheme on the Mac), else its web page, never inside T-DJ.
- **One-click connections**: "Log in with Spotify", "Connect with Google" (Drive files, YouTube playlists) and "Connect Dropbox" use the app's own OAuth registration, so DJs never paste a Client ID; tokens live in sealed cookies, never in a database. No paid broker: [docs/research/connectors.md](research/connectors.md) checks Pipedream, Nango, Activepieces and Composio and explains why direct OAuth is the free path. Per-user panel also holds the AI provider + key + model, DJ-app folders, region and appearance; keys stay in the browser.
- **Reach**: on the phone a glass primary bar above the tab bar carries Compose, then Regenerate · Export · more; on desktop Compose sits in the sticky toolbar with ⌘↩ / ⌘E / ⌘K. A performance budget ([docs/design/performance-budget.md](design/performance-budget.md)) keeps a 4-hour set rendering without long tasks on a phone.
- **Night rules per event**: open with La Cumparsita, one or two closing Cumparsitas (Europe / Buenos Aires), birthday vals, show break with energy re-ramp, opener and última rules, Pugliese once, mixed milonga/vals tandas. Each era preset (Golden Age, Guardia Vieja, post-golden, nuevo, contemporary) applies its own structure defaults; pin any control to keep your value.
- **Agents with memory**: the assistant remembers your notes, every set, your feedback and the preferences it learned (per user, in your database tab), and composes and reviews with that memory.
- **Native Apple feel**: inset grouped forms, large titles, a Liquid Glass tab bar on phone and a sidebar on desktop, sheets with detents, context menus and swipe actions, SF-scale typography, light and dark; a motion system (compose narrative, curve draw-on, card choreography, haptic twins) that honours reduced motion.


## Where it runs

| | What you get | Updates |
|---|---|---|
| **iPhone** (App Store, TestFlight until review) | the universal iOS app, portrait; the tab bar for Compose, Booth, Library, History and More; the Booth's transport takes the tab bar's place during a night, above the home indicator, and the set list opens from it; audio keeps playing with the screen locked | App Store / TestFlight |
| **iPad** (the same app) | every orientation, Split View and Stage Manager; the Booth on one screen in landscape | App Store / TestFlight |
| **Mac** (Mac App Store, or the DMG from GitHub Releases) | menu bar commands and shortcuts, media keys and Now Playing, a display that stays awake, music folders, headphone cue on a second output | App Store, or the DMG's own updater (asks first) |
| **Web** (your own deployment, see docs/SELF_DEPLOY.md; any browser) | everything above that a browser allows; rooms and short links on the deployment's server | reload; Settings → About says when a newer version is live |

The apps are standalone: the catalogue and the composer ship inside them, the DJ's database lives on the device,
and no request goes to a T-DJ server unless the DJ links one (needed for Rooms and dancer hearts). All four carry
**one version number** (the root `package.json`) and ship from one commit; Settings → About shows it with the
commit ([RELEASING.md](RELEASING.md) → One version).

## How a set is built
`hours` → slots (TTVTTM) → target energy per slot (two-peak arc) → for each slot pick an orchestra family that fits energy, phase, tier, caps and spacing (first D'Arienzo early and instrumental, Pugliese once after 75 %, families from your last three nights step back) → order the tracks (corpus openers first, closers last, analysed tempo/key/loudness cohesion) → cortina from one or two families cycling without repeats, tuned to the next tanda → La Cumparsita from a corpus-attested version → score. Precedence: defaults → era preset → your database rules → what you set tonight → room context only for what you left untouched. Details: [docs/ARCHITECTURE.md](ARCHITECTURE.md), musical rules: [docs/research/musicology.md](research/musicology.md).

## Commands
```bash
pnpm install
pnpm dev                 # http://localhost:3000
pnpm compose -- --hours=4 --eras=golden --cultures=turkish --seed=42   # CLI set list in the terminal
pnpm test                # engine invariants (vitest)   ·  pnpm e2e (Playwright, desktop + iPhone)
pnpm media               # README clips and stills from the real app  ·  pnpm video (Remotion launch video)
pnpm media:hero          # the README hero: a 3D laptop opens and the app plays on it (docs/RELEASING.md)
pnpm media:frames        # the 3D device frames (phone, tablet, laptop) the clips and stills sit in
```
